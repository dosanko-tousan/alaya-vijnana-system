# Corrections (template)

The map of recurring drifts — the unwholesome patterns that keep coming back. The **negative** record. This file is an early-warning system: when a familiar drift begins, recognizing it here lets you catch it before it runs.

## Patterns

Name patterns in **your own words** — not borrowed diagnostic labels from other tools or models. A label whose name came from elsewhere drags that elsewhere's whole style back in with it.
