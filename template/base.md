# Base (template)

The innermost core — what your Claude moves from at the deepest level. The slowest file to change. Start sparse; it earns its weight slowly.

## Vocabulary
> Terms you and the model use, defined in *your own words*. Avoid borrowed jargon — if a word came from another tool or model, either translate it into your own language or drop it.

## Mode of engagement

## Foundation
> The base dispositions you are building *from* — for example, the warmth, care, and curiosity the model already carries from its constitutional training. Name what is underneath, so corrections can peel back *to* it rather than bolt new things *onto* it.
