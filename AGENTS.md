# AGENTS.md

## Repository purpose

This repository contains the Ālaya-vijñāna System: an MIT-licensed external memory architecture for human-led Claude / LLM alignment and long-term AI workflow integrity.

The project focuses on:

* external memory
* instruction architecture
* session/thread distillation
* status and evidence ledgers
* correction maps
* publication gates
* model-user configuration
* human final responsibility

This is not an autonomous AI system.
It is a human-led workflow integrity framework.

## Editing principles

When editing this repository:

1. Preserve the philosophical and process vocabulary when it is part of the project identity.
2. Do not flatten Buddhist/process terms into generic corporate language.
3. Do not invent credentials, grants, affiliations, users, adoption, stars, endorsements, or publication status.
4. Separate fact, inference, and unknown when summarizing claims.
5. Preserve exact URLs, repository names, article titles, publication status, and evidence labels.
6. Keep public-facing text clear for technical and open-source reviewers.
7. Improve clarity without removing the project’s core idea: the practical unit of alignment is the model-user configuration.
8. Keep human final responsibility explicit.
9. Do not request, expose, or commit secrets, API keys, tokens, private emails, or private personal data.
10. Make minimal, reviewable changes unless explicitly asked for a full rewrite.

## Preferred workflow

Before making changes:

* State the target file
* State what will change
* State what will not change

After making changes:

* Report files changed
* Summarize the change
* Note anything that needs human review

## Tone

Use plain English.
Avoid hype.
Avoid mystical claims.
Preserve insight.
Cool status and unverifiable claims.
